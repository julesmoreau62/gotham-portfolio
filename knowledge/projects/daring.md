# Royal Daring HC — sponsor system built to outlive my internship (id: daring)
Royal Daring Club de Molenbeek, Brussels field hockey club founded in 1922. 19 teams from youth to senior, ~620 members, promotion to Division Honneur on the horizon. My role: Communication & Sponsoring intern, May → Jul 2026 (season 2025-26).

- Problem: how can an amateur club turn scattered communication into a coherent, credible, sponsor-ready identity that supports partner acquisition and long-term development, with limited people and money?
- Gap when I arrived: no structured visual identity, no sponsorship material beyond a static 3-tier PDF, no institutional LinkedIn, no reusable production workflow.
- Brand system: first graphic charter. Daring Red #C8102E, Black #0D0D0D, Gold #C9A84C, Off-white #F4F0E8. Playfair Display (headlines) + DM Sans (body). Canva template system across four formats: matchday, institutional, event, recruitment.
- Sponsor offer: rebuilt from a static 3-tier PDF into a 5-tier package + Youth Pack: field assets, jersey placements, LED board, match posters, social placements, CSR/youth framing, Business Club access. 22 existing partner logos integrated as social proof.
- Partner website: live, bilingual FR/NL, hosted on Netlify (https://rdaring-sponsor-only.netlify.app). Built in HTML, CSS and vanilla JavaScript with Claude Code and Codex.
- Partner brochure: 9-page PDF generated programmatically with Python + ReportLab.
- Social and signage: weekend recap carousel, matchday stories, playoff poster and T-shirt, bilingual summer camp posters, portrait template, physical bilingual signage around the club (snack bar, dogs, kitchen door, smoking area). Club LinkedIn page created.
- Continuity: Notion workspace with a playbook, an editorial charter (diagnostic vs target), 11 post templates (visual brief + caption + channel), a live task tracker, and a Markdown export so any AI assistant can pick it up.
- Funnel logic: awareness (social visuals) → credibility (brand system) → offer (website + brochure) → contact.
- Why it matters for digital transformation: it is a small-club system designed so volunteers can run it without me, which is the core idea of my work.
- Stack: HTML5, CSS3, JavaScript, Python, ReportLab, Netlify, GitHub, Claude Code, Codex, Canva, Notion.
