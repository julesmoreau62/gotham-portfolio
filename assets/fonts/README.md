# Fonts for the share images

Static instances of the site's fonts, read at build time by `lib/og-image.tsx`
(the image generator cannot use the variable WOFF2 files that `next/font` serves).
They are not served to visitors.

- `Archivo-SemiExpanded-Black.ttf`, `Archivo-SemiBold.ttf`: Archivo, SIL Open Font License 1.1 (`OFL-Archivo.txt`)
- `JetBrainsMono-Medium.ttf`: JetBrains Mono, SIL Open Font License 1.1 (`OFL-JetBrainsMono.txt`)

Source: Google Fonts.
